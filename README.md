# 시장 공략 지침

ChatGPT Work에 한 번 넣어 두면, 시장이나 주제를 한 줄만 던져도 그 시장의 공략 전략을 세워 주게 만드는 파일 묶음이다.

| 파일 | 하는 일 |
|---|---|
| `1-프로젝트지침.txt` | ChatGPT 프로젝트의 지침 칸에 붙여 넣는 글 |
| `2-공략규약.md` | 프로젝트에 파일로 올린다. 공략 전략을 세우는 순서와 전략서 양식이 들어 있다 |

## 설정

1. ChatGPT에서 새 프로젝트를 만든다. 메모리는 기본 메모리(Default memory)로 둔다. 프로젝트 전용 메모리를 고르거나 프로젝트를 남과 공유하면 그 프로젝트에서 Work를 쓸 수 없다.
2. 프로젝트 설정의 지침 칸에 `1-프로젝트지침.txt` 내용을 전부 붙여 넣는다.
3. 프로젝트에 `2-공략규약.md`를 올린다.

## 쓰는 법

프로젝트 안에서 Work를 고르고 생각나는 대로 쓰면 된다.

| 이렇게 쓰면 | 이렇게 한다 |
|---|---|
| `카카오톡 이모티콘` | 그 시장의 공략 전략서를 쓴다 |
| `카카오톡 이모티콘 > 캐릭터는 넘침 > 부부가 집안일로 톡 많이 함 > 집안일 시키는 이모티콘` | 화살표 뒤의 생각을 출발점으로 삼되, 실제 수요를 넓게 본 뒤 더 나은 자리가 있으면 그쪽으로 전략을 낸다 |
| 전략 문서를 붙이고 `검토해줘` | 전제를 확인하고, 고친 전략서를 낸다 |
| `더 넓혀`, `2번 깊게`, `같은 걸로 다른 데도` | 낸 전략서를 이어서 넓히거나, 공략점 하나를 깊게 파거나, 같은 생산 규칙으로 칠 다른 판매처를 찾는다 |

## 샘플

`샘플/`에는 이 지침으로 쓴 공략 전략서 본보기 세 편이 있다. 프로젝트에는 올리지 않는다. 올리면 Work가 다른 시장에도 이 내용을 끌어다 쓸 수 있다.

| 전략서 | 한 줄 공략 |
|---|---|
| 유튜브 쇼츠 | 모델명으로 찾는 "내 기계 설명서" 쇼츠를 모델마다 찍어 내고 부품을 쇼핑 태그로 판다 |
| 카카오톡 이모티콘 | 대화방에서 맡은 일을 받았다, 하는 중이다, 끝냈다고 알리는 말을 미니 이모티콘 리액션으로 방 종류마다 찍어 낸다 |
| Etsy 디지털 다운로드 | "내 것에 맞나?"부터 묻는 파일(모델별 바느질 도안, 주별 판매 라벨, 지역별 정원 계획)을 표 하나로 찍어 낸다 |
