# 시장 공략 전략

시장이나 주제를 한 줄만 던지면 그 시장의 공략 전략서를 써 주는 지침 묶음이다. ChatGPT Work와 Claude Code(Codex 포함)에서 같은 기준으로 쓴다.

전략서가 내는 것은 진입 판정이나 상품 목록이 아니다. 개나소나 몰리는 곳을 피해 수요는 있는데 경쟁을 덜 하는 시장 단위 공략점, 그리고 그 자리를 같은 규칙으로 끝없이 채울 생산 규칙과 찾아오게 하는 규칙이다. 전략서 맨 앞의 공략 카드만 보고도 자동화를 시작할 수 있게 쓴다.

| 파일 | 하는 일 |
|---|---|
| `1-프로젝트지침.txt` | 운영자가 원하는 것, 운영자의 말을 읽는 법, 원칙. ChatGPT 프로젝트의 지침 칸에 붙여 넣는 글이기도 하다 |
| `2-공략규약.md` | 절차와 공략 전략서 양식 |
| `AGENTS.md`, `CLAUDE.md` | Claude Code와 Codex가 이 저장소에서 따르는 안내 |
| `.claude/skills/market-attack/` | Claude Code에서 `/market-attack`으로 부르는 스킬 |
| `전략서/` | 지금까지 쓴 공략 전략서와 원자료. 목록은 `전략서/README.md` |

## Claude Code에서 쓰기

이 폴더에서 Claude Code를 열고 시장을 던진다.

```
/market-attack 유튜브 쇼츠
```

`/market-attack` 없이 "OO 공략해줘"라고 써도 된다. 전략서는 `전략서/전략서-<시장 이름>.md`에 쌓이고, 같은 시장을 다시 던지면 그 전략서를 고쳐 이어 간다. Codex에서도 이 폴더를 열면 `AGENTS.md`를 따라 똑같이 한다.

## ChatGPT Work에서 쓰기

1. ChatGPT에서 새 프로젝트를 만든다. 메모리는 기본 메모리(Default memory)로 둔다. 프로젝트 전용 메모리를 고르거나 프로젝트를 남과 공유하면 그 프로젝트에서 Work를 쓸 수 없다.
2. 프로젝트 설정의 지침 칸에 `1-프로젝트지침.txt` 내용을 전부 붙여 넣는다.
3. 프로젝트에 `2-공략규약.md`를 올린다. `전략서/`의 파일은 올리지 않는다. 올리면 Work가 다른 시장에도 그 내용을 끌어다 쓸 수 있다.
4. 프로젝트 안에서 Work를 고르고 시장을 던진다.

지침이 바뀌면 지침 칸과 프로젝트 파일을 다시 넣어야 ChatGPT 쪽에 반영된다.

## 던지는 법

| 이렇게 쓰면 | 이렇게 한다 |
|---|---|
| `카카오톡 이모티콘` | 그 시장의 공략 전략서를 쓴다 |
| `카카오톡 이모티콘 > 캐릭터는 넘침 > 부부가 집안일로 톡 많이 함 > 집안일 시키는 이모티콘` | 화살표 뒤의 생각을 힌트로 삼되, 시장 전체를 놓고 더 넓은 갈래를 잡는다. 생각이 맞으면 한 갈래의 첫 진입 지점으로 쓴다 |
| 전략 문서를 붙이고 `검토해줘` | 전제를 확인하고, 고친 전략서를 낸다 |
| `더 넓혀`, `2번 깊게`, `같은 걸로 다른 데도` | 낸 전략서를 이어서 넓히거나, 공략점 하나를 깊게 파거나, 같은 생산 규칙으로 칠 다른 판매처를 찾는다 |
