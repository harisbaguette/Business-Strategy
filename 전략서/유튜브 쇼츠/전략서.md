# 전략서 - 유튜브 쇼츠

- 작성일: 2026-10-15
- 수정일: 2026-10-20
- 상태: 실행 전 확인
- 바꾼 이유: 새 채널도 곧바로 쇼핑 수익을 낸다는 인상을 없애고, 구매 의도가 있는 검색 유입·제휴 자격·제작 검수 비용을 연결했다. 원자료의 채널명은 제거하고, 시장 전체에 경쟁자가 없다는 단정과 임의의 검수 비율을 없앴다.

> 2026-10-20 후속 전제 변경: 아래는 AI 제작·대량 생산·자동화를 고정 전제로 강화하기 전의 전략이다. 9번의 AI 역할을 보조 작업에 한정한 부분, 검증 자동화, 같은 AI를 쓰는 경쟁자 대비 가치, 국내·해외 고객 선택을 다시 설계해야 한다. 이번에는 이 적용 범위만 표시했으며 정책·시장 조사를 새로 완료한 것으로 보지 않는다.

## 0. 공략 카드

- **한 줄 공략.** 기기 모델별 소모품 선택·교체 문제를 정확하게 풀고, 제휴 자격을 갖춘 뒤 맞는 부품 구매에 연결한다.
- **주력.** 집 기기 소모품 선택·교체. 브랜드 × 실제로 다른 모델 묶음 × 작업으로 넓히며 승인된 제휴 거래로 번다.
- **보조.** 사용자 조치가 가능한 에러 안내로 같은 고객의 문제를 풀고 관련 관리 영상으로 잇는다.
- **생산 규칙.** 공식 설명서의 적용 모델·작업·부품·주의점·출처를 묶고, 절차가 같으면 한 편으로 만든다.
- **유입.** 모델명 검색 → 짧은 해결 안내 → 같은 채널의 상세 영상 또는 허용된 상품 태그 → 승인된 구매·정산이다.
- **시작 비용.** 공개 자료 비교는 추가 결제 없이 한다. 제작 도구·사진 권리·필요한 실물 검증 비용은 별도로 잡는다.
- **반복 수고.** 모델·부품 정확성, 링크·재고·정책 변경, 문의를 확인한다. 매일 홍보 댓글을 다는 방식은 쓰지 않는다.
- **돈이 남을 조건.** 제휴 승인과 구매 전환이 성립하고, 반품을 뺀 수수료가 자료 확인·제작·갱신 비용을 넘겨야 한다.
- **첫 확인.** 한 기기군에서 무료 설명서의 빈틈, 검색 공급, 실제로 구매 가능한 부품과 제휴 조건을 먼저 맞춘다.
- **다음 확장.** 같은 원본의 상세 영상·검색 자료를 먼저 붙이고, 다른 플랫폼은 그곳의 링크·정산 조건을 확인한 뒤 늘린다.
- **핵심 미확인.** 새 채널의 검색 유입량·구매율·수수료율과 모델별 확인 시간이다. 초기 제휴 매출은 0으로 둔다.

## 1. 한 줄 공략

고장 수리 전반으로 넓히지 않고, **모델별로 어떤 소모품을 골라 어떻게 바꾸는지 찾는 사람**을 유튜브 검색에서 만나, 검증한 설명과 부품 구매 연결의 대가를 받는다.

## 2. 정한 가정

한국의 새 채널, 기존 구독자 없음, 유료 광고 없음이다. 운영자가 모든 기기를 소유한다고 가정하지 않는다. 실물 확인이 필요한 작업은 확인 가능한 기기부터 고르며, 자료만으로 안전과 적용 조건을 판단하지 못하면 해당 작업의 제작을 미룬다. 음성·편집 도구는 가진 수단을 우선 쓴다.

## 3. 시장

시청자는 해결 안내를 무료로 보고, 구매자는 판매처에 부품값을 낸다. 판매처가 인정한 제휴 거래에 대해서만 운영자가 수수료를 받는다. 광고 수익과 제휴 수익은 서로 다른 조건이다.

| 경로 | 2026-10-20 확인 내용 | 전략에 적용 |
|---|---|---|
| 확장 YPP | 구독자 500명·90일 공개 업로드 3개와, 12개월 시청 3,000시간 또는 90일 Shorts 300만 회 조건 등이 있다 | 조건 달성 전 수익으로 계산하지 않는다 |
| YouTube Shopping 제휴 | YPP, 해당 구독 기준·국가·채널 유형 등 자격을 요구하며 Studio에서 참여한다 | 한국이 대상이어도 새 채널에 즉시 태그 기능이 있다고 가정하지 않는다 |
| 제휴 정산 | 판매처별 수수료·귀속 조건이 다르고 반품 시 수수료가 취소된다. 안내상 구매 후 60~120일 지급이다 | 매출 발생과 현금 수령을 나눈다 |
| 광고와 향후 변경 | 공식 안내는 2027-02-01 신규 광고 수익 자격 변경 및 Shorts Creator Pool의 월별 성과 조건을 예고한다 | 조회수만으로 사업 손익을 맞추지 않는다. 시행일 전에 다시 확인한다 |

근거는 [확장 YPP](https://support.google.com/youtube/answer/13429240?hl=en), [Shopping 제휴](https://support.google.com/youtube/answer/13376398?hl=en), [2027년 변경 안내](https://support.google.com/youtube/answer/12843009?hl=en)다. 자격 숫자만 채우면 자동 승인되는 것은 아니다.

## 4. 개나소나 하는 것

2026-10-15 [검색 표본](원자료-2026-10-15.csv)에는 AI 사연·동물·영화 요약·범용 쇼핑 추천이 반복된다. 표본 863행은 검색 결과 관측 수이며 고유 영상 수나 시장 전체 규모가 아니다. 원본 URL·영상 ID가 없어 현재 순위와 개별 결과의 재현에는 한계가 있다.

경쟁에는 제조사 설명서·공식 영상·부품 판매처·개인 관리 영상도 포함한다. “브랜드를 가리지 않는 경쟁자가 없다”는 종전 표현은 철회한다. 기존 무료 자료가 이미 정확하고 쉬운 모델에 새 영상만 덧붙이지 않는다.

## 5. 고객 수요

| 이용자 상황 | 현재 대안과 빈틈 | 돈을 쓰는 지점 |
|---|---|---|
| 교체할 필터를 찾는다 | 설명서·상품 페이지의 모델 표기가 달라 호환을 비교해야 한다 | 맞는 소모품 구매. 안내만 보고 다른 판매처에서 살 수도 있다 |
| 에러가 떠서 급히 확인한다 | 공식 안내가 길거나 자기 모델 적용 여부를 모르겠다 | 청소로 끝나면 구매가 없다. 필요한 작업에만 부품을 연결한다 |
| 차 소모품 규격을 찾는다 | 연식·세대·장착 방식이 섞인다 | 규격이 확인된 소모품 구매. 실수 비용이 커 확인 부담도 높다 |

표본의 조회는 정보 수요의 흔적이다. 내 영상의 구매율·수입을 입증하지는 않는다. 고객이 원하는 것은 “새 영상”보다 적용 모델·필요한 물건·멈춰야 할 지점이 분명한 답이라는 가설로 시작한다.

## 6. 시장 공략점과 첫 진입 지점, 타깃

| 순서 | 공략점과 타깃 | 넓이·도달 | 돈과 수고 | 판단 |
|---|---|---|---|---|
| 1 | 필터·소모품을 직접 고르는 기기 소유자 | 모델 묶음 × 작업, 모델 검색 | 구매와 가깝지만 부품 정확성·갱신 검수가 필요하다 | 공식 사용자 교체 절차와 부품 표기가 명확한 기기군부터 시작한다 |
| 2 | 사용자 조치 에러를 찾는 소유자 | 같은 기기의 코드·관리 문제 | 구매가 없는 해결도 많다 | 주력과 같은 고객일 때만 보조로 붙인다 |
| 3 | 차 소모품을 직접 고르는 소유자 | 차종·세대·부품 | 규격 오류와 실물 검증 부담 | 집 기기에서 자료 검수·수익성이 확인된 뒤 별도 필요를 비교한다 |

경쟁이 덜하다는 판단은 아직 가설이다. 표본에서 비어 보이는 이유가 낮은 검색 수요이거나 실물 확인 비용일 수 있다. 첫 진입은 **사용자가 직접 교체하도록 안내된 공기청정기 필터의 선택·교체**다. 기존 표본의 공기청정기 검색에서 시작해 공식 자료로 적용 모델을 묶는다. 먹는 물·가스·전기 분해가 걸린 작업까지 동시에 넓히지 않는다. 새 모델이라는 이유만으로 먼저 만들지 않는다.

## 7. 그 고객이 마음에 쏙 들 공략

첫 화면에 적용 모델과 안 맞는 모델을 구분한다. 소모품의 식별 코드, 사용자 작업 범위, 단계, 완료 확인을 보여 준다. 제조사 자료에서 확인한 주의점과 운영자의 추론을 섞지 않는다. 정품·호환품 비교는 근거가 있는 항목만 다루고, 확인하지 않은 절약액이나 “직접 해도 안전하다”는 판단을 만들지 않는다.

영상은 필요한 답을 실제로 제공한다. 무료 답을 일부러 숨겨 링크를 누르게 하지 않는다. 구매 링크는 해결에 필요한 물건을 정확히 찾는 수고를 덜어 줄 때 붙인다.

## 8. 적은 돈과 손으로 찾아오게 하는 법

주력은 `브랜드 + 모델명 + 부품/작업` 검색이다. 제목·첫 화면·설명에 적용 범위가 일치하도록 하고, 같은 기기군의 재생목록으로 이어 준다. 초기 검색 노출은 보장되지 않으므로 조회가 없으면 색인·검색어·경쟁 결과부터 확인한다.

이동 경로는 **모델 검색 → Shorts의 해결 안내 → 관련 상세 영상**, 자격을 갖춘 뒤에는 **영상 → 정확한 부품 태그 → 제휴 구매**다. Shorts 설명·댓글의 일반 URL은 클릭되지 않는다. [링크 위치 안내](https://support.google.com/youtube/answer/13748639?hl=en)

| 처음 할 일 | 반복할 일 | 줄이는 방법 |
|---|---|---|
| 한 기기군의 모델·부품 근거, 제목 형식, 설명·미리보기 준비 | 적용 정보·품절·링크·오류 문의 확인 | 같은 부품과 절차를 공유하는 모델은 하나로 묶는다 |
| 관련 영상과 재생목록 연결 | 검색 유입·이동·승인 거래 확인 | 성과가 난 기기군부터 고치고 넓힌다 |

댓글 영업이나 무관한 채널의 재게시를 필수로 두지 않는다. 유료 도구·광고·부품 구입은 공개 자료 조사에서 필요성이 확인된 뒤 비용으로 잡는다. 별도 제휴 프로그램은 가입·매체·링크 조건을 확인하기 전까지 초기 수익 대안으로 약속하지 않는다.

## 9. 계속 만드는 규칙

생산 단위는 **기기군 × 실제로 다른 모델 묶음 × 작업 × 부품**이다. 원본 자료에는 적용 범위·작업 단계·부품 식별자·출처·확인일·주의점·검수 결과를 남긴다. 같은 절차와 답이면 모델별로 쪼개지 않는다.

AI는 자료 정리·초안·도식화·누락 탐지에 쓰고, 공개 전 적용 모델·부품·작업 범위는 전건 확인한다. 두 사이트가 같은 자료를 복사했을 수 있으므로 일치만으로 정확성을 확정하지 않는다. 임의로 “나머지 10분의 1만 검사”하지 않는다.

같은 공식 적용표와 절차를 이미 확인한 경우 그 검수 결과를 재사용한다. 원본 변경·모델 차이·불일치를 먼저 가려 사람이 확인할 곳을 줄인다. 전건 확인은 매번 사람이 모든 자료를 처음부터 읽으라는 뜻이 아니다.

긴 영상은 여러 Shorts를 기계적으로 이어 붙이지 않고, 처음부터 끝까지 실제 과업이 완결되는 순서로 다시 검수한다. 제작·검수 시간이 줄어드는지 측정하고, 확인할 수 없는 모델은 늘리지 않는다. 가스·전기 분해·냉매·의료 효능처럼 검증 범위를 벗어나는 작업은 이 공략에 넣지 않는다.

## 10. 돈이 남고 오래 버는 법

`승인 제휴 수익 = 유효 상품 이동 수 × 승인 구매율 × 건당 수수료`다. 가격·수수료·반품·지급 지연을 반영하고, 제작·도구·실물 확인·갱신·문의 비용과 시간을 별도로 뺀다. 지금은 필요한 실적이 없으므로 월수익을 제시하지 않는다.

초기에는 제휴 수익 0에서도 감당할 수 있는 조사·제작 범위를 정한다. 수익 기능을 갖춘 뒤에도 클릭이 실제 승인 거래로 이어지는지 확인한다. 광고 수입이나 일시 보너스로 기본 비용을 맞추지 않는다.

오래 남길 것은 검증한 적용 모델·부품 대응표와 정정 기록이다. 취소가 많다는 사실만으로 부품 불일치라고 결론 내리지 않고 사유를 확인한다. 반복 교체 수요는 재방문 가능성이며 구독 수익을 보장하지 않는다.

## 11. 조심할 점

반복·대량 템플릿 콘텐츠의 수익 제한, 자료·사진 권리, 정확성, 제휴 표시와 이동 조건을 확인한다. 형식을 다르게 꾸미거나 업로드 간격을 벌리는 것만으로 정책에 맞는다고 판단하지 않는다. [채널 수익 창출 정책](https://support.google.com/youtube/answer/1311392)

YouTube Shopping 제휴 링크는 플랫폼 밖 공유가 제한된다. 다른 매체에는 그 매체에 허용된 별도 경로를 검토한다. 원본 자료와 편집 파일은 유지할 수 있지만 채널 순위·자격·구독자를 다른 곳으로 그대로 옮길 수는 없다.

## 12. 보면서 고칠 것

첫 확인은 한 기기군의 공개 자료와 기존 검색 결과 비교다. **모델 적용·부품·작업이 일치하고 기존 자료보다 나은 설명이 가능한지** 확인할 때까지 유료 제작을 늘리지 않는다. 실제 게시와 판매 실험은 운영 단계에서 한다.

| 관찰 | 다음 수정 |
|---|---|
| 검색 노출이 없다 | 검색어·색인·경쟁 결과를 먼저 고치며 구매 수요 실패로 단정하지 않는다 |
| 시청은 있으나 다음 행동이 없다 | 해결만 필요한 고객인지, 링크 위치·자격·필요 물건이 맞는지 본다 |
| 이동은 있으나 승인 거래가 없다 | 호환·가격·재고·귀속·취소 원인을 구분한다 |
| 수익보다 검수·문의 시간이 크다 | 확인이 쉬운 기기군으로 범위를 조정하고 신제품 확대를 멈춘다 |

비용 한도는 외부 제휴 수익 없이 부담 가능한 금액 안에서 잡는다. 최소한 첫 정산과 반품 반영 전에는 확대 수익성을 확정하지 않는다. 표본이 부족하면 판단 보류로 남긴다.

## 13. 같은 자산으로 넓힐 시장

| 순서 | 확장 | 그대로 쓸 것·새로 할 일 | 착수 조건 |
|---|---|---|---|
| 1 | 같은 채널의 상세 설명·전체 관리 안내 | 자료·도식 재사용, 전체 절차와 시청 흐름 재검수 | Shorts에 없는 설명을 실제로 필요로 할 때 |
| 2 | 모델별 검색용 글·찾아보기 | 적용표 재사용, 웹 유입과 허용된 구매 경로 마련 | 고객이 글·표로 비교할 필요가 보이고 갱신을 같이 할 수 있을 때 |
| 3 | 네이버 클립 등 다른 매체 | 원본 영상 재사용, 링크·제휴 자격·규격 재확인 | 신규 고객 유입과 추가 운영비를 확인한 뒤 |

새 판매처가 수익을 곱해 준다고 계산하지 않는다. 같은 고객의 중복 시청을 새 구매자로 세지 않는다.

## 14. 다음에 발굴할 시장

모델명 혼동·단종 부품·교체 후 알림 초기화처럼 구매 전후의 반복 질문을 찾는다. 현재 자료와 연결되는 **호환 부품 선택 자료**, **오래된 기기의 사용자 관리 안내**가 후보이다. 각각 무료 제조사 안내의 빈틈, 공급 가능한 부품, 구매 연결 가능성을 먼저 확인한다. 수리 전반이나 지역 생활 정보처럼 고객과 돈의 흐름이 달라지는 갈래는 별도 근거 없이 붙이지 않는다.

## 15. 반론과 확인할 전제

| 강한 반론 | 반영한 수정 | 남은 확인 |
|---|---|---|
| 제조사 무료 영상이면 충분하다 | 차이가 있는 모델·선택 문제만 다룬다 | 실제 검색 결과와 고객 질문 비교 |
| 새 채널은 태그를 못 단다 | 초기 제휴 매출 0, 승인 뒤 경로 분리 | 운영자의 Studio 자격·약관 |
| 기기 없이 만든 안내는 틀릴 수 있다 | 전건 근거 확인, 필요한 실물 확인을 비용에 포함 | 작업별 확인 가능 범위·시간 |
| 모델별 검색량이 너무 적다 | 조합 수로 규모를 주장하지 않는다 | 공개 후 유효 유입·승인 거래 |
