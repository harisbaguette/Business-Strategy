## 원자료 설명

[원자료-2026-10-15.csv](원자료-2026-10-15.csv)는 검색어 22개, 863개 관측 행이다. 정리 때 행 순서와 나머지 필드값을 그대로 보존하고 채널명 열만 제거했다. 정리 전 완전히 같은 행을 제외한 수는 848개지만, 고유 영상 수는 아니다. 중복을 임의 삭제하면 검색별 노출 맥락이 달라져 그대로 보존했다.

| 열 | 뜻·한계 |
|---|---|
| 확인일 | 검색을 수집한 날짜 |
| 검색어 | 입력한 검색 문구 |
| 형식 | 검색 결과의 일반 영상·쇼츠 구분 |
| 제목 | 결과에 표시된 제목. 동일 제목만으로 동일 영상을 확정하지 않는다 |
| 조회수 | 화면에 표시된 문자열. 누적 조회와 검색 유입을 구분할 수 없다 |
| 올린 때(일반 영상만) | 수집 당시의 상대 날짜. 정확한 발행일로 바꾸지 않는다 |

영상 URL·ID·검색 지역·로그인 조건이 원자료에 없다. 지금 만들어 넣지 않는다. 이 표본으로 시장 전체 수요·고유 경쟁자 수·구매율을 계산하지 않는다. 새로 수집할 때는 실제 조회 주소나 콘텐츠 ID, 수집 조건을 함께 남긴다.
