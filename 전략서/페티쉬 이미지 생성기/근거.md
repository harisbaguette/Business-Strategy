## 3. DB 재조회

SQLite URI에 `mode=ro`를 붙여 `tags` 테이블의 행 수와 지표 분포만 조회했다. 개인 정보나 계정 데이터를 추출하지 않았다.

```sql
SELECT COUNT(*) FROM tags;
SELECT SUM(artwork_count > 0), SUM(artwork_count = 0), SUM(artwork_count IS NULL) FROM tags;
SELECT SUM(access_count > 0), SUM(access_count = 0), SUM(access_count IS NULL) FROM tags;
SELECT SUM(demand_score > 0), SUM(demand_score = 0), SUM(demand_score IS NULL) FROM tags;
SELECT SUM(r18_count > 0), SUM(r18_count = 0), SUM(r18_count IS NULL) FROM tags;
```

| 지표 | 양수 | 0 | NULL |
|---|---:|---:|---:|
| `artwork_count` | 46,307 | 191 | 0 |
| `access_count` | 0 | 46,498 | 0 |
| `demand_score` | 0 | 46,498 | 0 |
| `r18_count` | 0 | 46,498 | 0 |

총행은 46,498이다. 0을 실제 수요 없음이라고 해석하지 않는다. 지표의 수집·갱신·정의가 확인되지 않아 현재 수요 순위에 사용할 수 없다는 결론이다. 저장된 작품 수를 고객 수·구매 수로 바꾸지 않았으며 이 DB를 판매 원자료로 내보내지 않았다.

## 4. 공식 원문 수신과 날짜 처리

Pixiv 약관·가이드라인·개정 공지와 Patreon 커뮤니티 가이드라인은 `curl.exe`로 현재 본문을 받았다. 도움말의 짧은 URL 다수는 `403`을 반환했다. Pixiv 검색 도움말은 `r.jina.ai` 중계 수신과 웹 도구의 공식 원문 열기로 교차 확인했고, 나머지는 전체 제목 URL을 이용한 공식 원문 열기 등으로 확인했다. 접근 실패를 규칙 없음으로 해석하지 않았다. 원본 HTML·중계 텍스트·추출 스크립트는 시스템 임시 폴더에서 다루며 저장소에 대용량 사본을 넣지 않았다.

실제 확인일은 모두 2026-10-22다. 아래 개정일은 직접 본 문서 표시이며 적용일과 구분한다. 상대적인 ‘몇 달 전’ 표시는 개정일로 계산하지 않았다. 영어 미국판과 영국판의 수정 표시가 다른 페이지는 직접 열린 미국판의 날짜를 기록했다. 웨이백 사본은 사용하지 않았다.

### 단건 판매 안내와 성인 유료 벽 표현

T3·T4는 성인 계정의 단건 판매를 명시한다. T1은 성인 작품 설명에서 `subscription paywall`이라는 표현을 사용한다. 기능 허용을 모든 성적 내용의 단건 허용으로 넓히지 않았다. 첫 실행안은 비노골적 일반 일러스트이며 다른 범위의 상품은 공식 확인과 실제 계정 상태가 남는다. 기존의 성적 방향을 일반 그림으로 바꿨을 때 같은 고객이 계속 산다는 주장도 하지 않는다.

### 자동화 근거의 범위

## 8. 관측과 계산과 제안의 구분

| 내용 | 성격 | 한계 |
|---|---|---|
| 14개 주제와 그 설정·DB 분포 | 로컬 관측 | 구매 데이터가 아니다 |
| AI 작품 공급이 이미 대규모였음 | 2024 연구의 역사적 관측 | 2026년 현재 분류별 경쟁도·매출로 쓸 수 없다 |
| 06부터 시작, 14 다음 비교 | 운영 부담에 대한 판단 | 실제 상품성·판매성 순위가 아니다 |
| 단건 $5 | 첫 시험 제안 | 경쟁 가격 조사·최적가·사용자 확정 가격이 아니다 |
| 생성·지원·환불 비용 | 미측정 변수 | 0이라고 가정하지 않는다 |
| 단건 우선이 구독보다 편할 수 있음 | 거래 의무에 대한 비교 | 지속 매출이 더 높다는 주장은 아니다 |

[Pixiv 연구](https://arxiv.org/abs/2402.18463)는 2024-02-28 제출됐고, 1,520만 게시물 중 240만 AI 이미지가 포함된 자료를 분석한다고 초록에 명시한다. 이 연구를 14종의 지불 의사 근거로 사용하지 않았다. 개인 제작자 이름·연락처·계정별 판매 정보는 저장하지 않았다.

계산은 다음과 같다. 어느 값도 실적으로 표시하지 않았다.

- 신규 표준·USD·세금 없는 카드 결제 두 수수료 후: `P × (1 − 0.10 − 0.029) − 0.30 = 0.871P − 0.30`이다.
- 같은 조건의 미국 외 PayPal 결제: `0.861P − 0.30`이다. 여기서 결제 처리와 출금은 다른 단계다.
- $5 결제 28건의 카드 수수료 후 합: `28 × 4.055 = 113.54`다.
- 14계정·하루 2건·30일은 840게시다. 매번 30초면 7시간, 3분이면 42시간이다.
- 14일 부재 시 같은 일정은 `14 × 2 × 14 = 392`게시다. 실제 예약·성공 건수가 아니다.
- 중간 단계 통과율 60%라는 가정에서 같은 전환을 유지할 후속 배율은 `1 / 0.6 ≈ 1.67`이다.
- 0건 관측의 단측 95% 구매율 상한은 `1 − 0.05^(1/n)`이다. 필요율이 가정상 1%일 때 `ceil(log(0.05) / log(0.99)) = 299`다. 독립·유효 방문을 전제하므로 단순 조회수로 계산하지 않는다.

## 10. 공개 이용자 진술의 작은 관측 자료

[원자료-2026-10-22.csv](원자료-2026-10-22.csv)는 실제로 연 공개 댓글 두 건의 비노골적 요약이다. `site:reddit.com "AI art" "Patreon" "pay" "generate myself"` 등 구매 동기를 찾는 검색에서 발견한 토론 하나를 열고, 자신이 구독한다고 말한 댓글 두 건의 고유 주소를 확인했다. 확률 표집도 전체 댓글의 체계적 조사도 아니다. 2026-10-22에 확인했지만 개별 댓글 날짜는 원문이 상대 날짜만 보여 절대 날짜를 기록하지 않았다.

이용자 이름·연락처·계정별 매출 주장·노골적 묘사는 저장하지 않았다. 두 진술 모두 영수증과 실제 구매 내역으로 검증하지 못했다. 원문에 함께 나오는 제3자의 매출 추정, 플랫폼에 관한 의견, 영상 때문에 제한받았다는 전언을 사실로 채택하지 않았다. 두 명을 시장 전체의 구매자 비율로 계산하지 않는다.

CSV 한 행은 댓글 하나이며 중복 댓글은 없다. 같은 토론에서 나온 표본이라 서로 독립적인 시장 관측으로 합산할 수 없다. 열은 다음과 같다.

- `sample_id`: 이 문서에서 붙인 표본 식별자다. 플랫폼 ID나 이용자 ID가 아니다.
- `source_url`: 직접 연 댓글 고유 주소다.
- `source_date`: 확인 가능한 절대 작성일이다. 두 빈칸은 미확인이며 0일·작성일 없음이라는 뜻이 아니다.
- `observed_date`: 직접 확인한 날짜이며 `YYYY-MM-DD`, Asia/Seoul 기준이다.
- `evidence_type`: 영수증 대신 자기 진술을 요약했다는 자료 성격이다.
- `summary`: 관측한 내용을 비노골적으로 바꾼 한국어 요약이며 원문 인용이 아니다. 세 곳이라는 수는 해당 진술의 주장이다.
- `limitation`: 결제·상품·유지 기간 등 확인하지 못한 범위다.

따라서 전략서의 ‘이 프로젝트의 수요·수익은 미검증’ 결론을 바꾸지 않는다. 공개 토론에도 결제 진술이 있다는 정도로만 반영했다.
