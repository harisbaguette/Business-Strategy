# 시장과 프로젝트별 전략서

시장이나 프로젝트마다 폴더 하나를 두고, 그 안의 `전략서.md` 하나가 저장된 최신본이다. 앱이나 채널처럼 다른 폴더에서 만드는 프로젝트는 전략서 맨 위의 `연결 폴더`에 그 경로를 적는다. `근거.md`에서 공식 출처·실제 확인 범위·표본 한계를 본다. 행 수나 조회수는 매출 검증이 아니다.

**2026-10-20 후속 전제 변경:** AI 제작·대량 생산·자동화, 같은 AI를 쓰는 경쟁자와의 가치 비교, 국내외 고객 검토를 고정 기준으로 강화했다. 유튜브 쇼츠·카카오톡 이모티콘·Etsy의 세 전략은 이 기준으로 전면 재설계된 상태가 아니다. 각 첫머리에 충돌·보완 범위를 표시했다. 특히 카카오 전략의 사람 제작 전환은 현재 운영자의 실행안으로 사용하지 않는다. 같은 시장을 이어갈 때 기존 수요·근거를 재사용하되 새 기준으로 공략 경로를 고친다.

유튜브 쇼츠·카카오톡 이모티콘·Etsy의 기존 공략 목적·문서 논리와 주요 정책 점검은 위 후속 전제 변경 전에 수행했다. 같은 날짜의 기록이어도 새 전제의 충족을 뜻하지 않는다. 페티쉬 이미지 생성기 전략은 새 전제로 작성했지만 실제 게시·구매·정산·무인 운영 실험을 한 것은 아니다. 각 전략의 12번에서 첫 확인, 15번에서 남은 전제를 본다.
